# 09 — 冻结 10,000 条训练数据与评估集合

**What to build:** 合并 good 与非 good cohort，形成版本锁定、MD5 隔离、可复现切分的 10,000 条正式数据集，并建立能力保持集和四档学习曲线清单。

**Blocked by:** 07 — 完成 6,500 条 good 数据纵向生产；08 — 完成 3,500 条非 good 数据纵向生产

**Status:** ready-for-agent

- [ ] 正式数据集恰为 10,000 条，类别、小类和 `good_risk_signal` 方向分布均满足规格。
- [ ] 使用记录的固定随机种子形成 9,000 条 train 和 1,000 条 dev。
- [ ] 相同 MD5 不会跨 train/dev，也不会同时出现在正式数据与能力保持集。
- [ ] SFT 与 GRPO 引用完全相同的 train/dev 清单，不在各训练阶段重新切分。
- [ ] 建立 200～500 条不参与训练的能力保持集，覆盖 OCR、UI、文档、细节识别、GIF 时序和 JSON 稳定性。
- [ ] 建立嵌套或明确可比较的 2.5k、5k、7.5k、10k 学习曲线训练清单。
- [ ] 主训练清单不含未经统一生产契约改写的公开原始数据。
- [ ] 冻结产物包含校验报告、数据指纹、完整版本谱系和可重复生成清单的命令记录。
