# 使用有界动态分辨率与单个 GIF Video 帧列表

所有数据制作、SFT、GRPO、评估和部署阶段统一媒体语义：静态图作为单个 image，由 Qwen3-VL processor 在 `IMAGE_MAX_TOKEN_NUM=1024`（`max_pixels=1048576`）内使用动态分辨率；超限时只等比例缩小，不裁剪或改变宽高比。GIF不超过4帧时全部使用，超过4帧时按累计播放时间的 `0、1/3、2/3、1` 位置选取4帧，并将有序帧作为一个 video 帧列表输入；每帧使用 `VIDEO_MAX_TOKEN_NUM=256`（`max_pixels=262144`），不得表示成四张独立 image。该决定同时约束媒体管道版本与真实视觉token长度统计，避免静态图预算被错误乘到每个GIF帧或训练/部署时序语义漂移。
